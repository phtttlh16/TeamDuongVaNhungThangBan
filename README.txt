TEAM DƯƠNG & ĐỒNG BỌN — DASHBOARD DEMO

CÁCH DÙNG
1. Mở index.html trong trình duyệt để xem thử.
2. Tài khoản demo: admin
   Mật khẩu demo: Duong@2026
3. Vào Hồ sơ công việc > Thêm hồ sơ để nhập mã hồ sơ, người phụ trách, trạng thái và ghi chú.
4. Xem Tổng quan / Thống kê; có thể xuất CSV mở bằng Excel.

ĐƯA LÊN GITHUB PAGES
1. Đăng nhập https://github.com và mở repository của bạn.
2. Tải index.html lên (ví dụ repository teamduongthonu) rồi Commit changes.
3. Vào Settings > Pages.
4. Chọn Deploy from a branch > Branch main > /(root) > Save.
5. Chờ vài phút rồi mở link Pages của repository.

LƯU Ý BẢO MẬT RẤT QUAN TRỌNG
- Đây là BẢN DEMO frontend. Tài khoản/mật khẩu được lưu trong mã JavaScript, ai xem mã nguồn cũng có thể thấy.
- Dữ liệu hồ sơ lưu trong localStorage trên trình duyệt/thiết bị hiện tại; không có cơ sở dữ liệu dùng chung, không đồng bộ cho nhiều admin.
- Không dùng để lưu dữ liệu cá nhân nhạy cảm hoặc vận hành thực tế trước khi có backend, xác thực an toàn, phân quyền, nhật ký truy cập và sao lưu.
- Tránh thu thập dữ liệu cá nhân trái phép; chỉ nhập dữ liệu cần thiết mà bạn có căn cứ hợp pháp để xử lý.
